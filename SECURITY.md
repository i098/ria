# Security policy

Report a vulnerability in private. Do not open a public issue.

Use [GitHub private vulnerability reporting](https://github.com/i098/ria/security/advisories/new). Give the steps to reproduce, the effect, and the commit you tested.

You get a first answer in 7 days. Only the `main` branch is supported. Ria has no release yet.

A vulnerability in Ardia or in its engine belongs to [Ardia](https://github.com/ardia-browser/ardia).
