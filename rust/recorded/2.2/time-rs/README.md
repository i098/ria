## Clock

`ago` reads `Date.now()` when the caller gives no `now`.
Use the clock hook and the same `RIA_NOW_MS` for `record`, `diff`, `gate`, and `fuzz`, from the repository root:

```sh
TZ=UTC RIA_NOW_MS=1795417631295 NODE_OPTIONS=--import=$PWD/rust/recorded/2.2/time-rs/clock-freeze.mjs \
  rust-anything diff rust/recorded/2.2/time-rs
```

`time.ts` reads no time zone or locale, so it has no difference outside UTC.
