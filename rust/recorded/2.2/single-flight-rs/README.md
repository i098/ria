# single-flight-rs

Rust port of `apps/browser/src/lib/singleFlight.harness.ts`, bridged with napi-rs. Generated by rust-anything.

The unit is `singleFlight.ts` through the harness [`singleFlight.harness.ts`](../singleFlight.harness.ts). The harness
runs flights until it has used each pass. Each pass waits once, then can call the flight again (join), ask to repeat, and fail.
The log records each pass, join, `again`, `keepGoing` answer, and the end of each flight.
The Rust port (`ria_state::shared::single_flight`) is synchronous: a join is a reentrant `run` call.
