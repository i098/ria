# window-tint-rs

Rust port of `apps/browser/src/lib/windowTint.ts`, bridged with napi-rs. Generated by rust-anything.

Arguments outside the TS types are not covered: the Rust side takes typed values, so the crate is recorded with `--count 0` (only `inputs/` cases and the calls of the original's tests). In-type inputs include the `null` and `undefined` cases where the TS throws.
