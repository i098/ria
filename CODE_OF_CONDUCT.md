# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful. Give and accept constructive feedback. Take responsibility for your mistakes. Focus on what is best for the project.

Not acceptable: harassment, insults, sexualized language or attention, personal or political attacks, publishing private information of others, and other conduct that is unprofessional in a project setting.

## Enforcement

Maintainers remove, edit or reject contributions that break this code, and can ban a person for conduct they judge harmful. This applies in all project spaces and when a person represents the project in public.

Report a problem in private through [GitHub private vulnerability reporting](https://github.com/i098/ria/security/advisories/new) with the title "Conduct report", or write to the maintainer [@i098](https://github.com/i098) on GitHub. Maintainers keep the reporter private.

Maintainers apply the [enforcement guide of the Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, permanent ban.
